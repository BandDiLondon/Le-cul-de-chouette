# Code de conduite

Le Cul de Chouette est un projet de fan, fait pour s'amuser. Ce code de conduite s'applique partout où l'on participe au projet : issues, pull requests, discussions et commentaires.

## Ce que l'on attend de chacun

- Être respectueux et bienveillant, y compris quand on n'est pas d'accord.
- Critiquer les idées et le code, jamais les personnes.
- Accueillir les débutants : tout le monde a commencé un jour.
- Accepter les remarques constructives, et savoir reconnaître ses erreurs.

## Ce qui n'est pas accepté

- Les insultes, les moqueries, les attaques personnelles.
- Le harcèlement, sous quelque forme que ce soit.
- Les propos ou images discriminatoires, sexuels ou violents.
- La publication d'informations privées sur quelqu'un sans son accord.

Les répliques de *Kaamelott* restent les bienvenues, tant qu'elles ne servent pas à rabaisser quelqu'un.

## En cas de problème

Si vous êtes témoin ou victime d'un comportement inacceptable, prévenez le responsable du projet en privé, depuis son profil GitHub. Les signalements sont traités avec discrétion.

Le responsable peut retirer des commentaires, des issues ou des contributions qui ne respectent pas ce code, et exclure du projet une personne qui le transgresse de façon répétée.

*Ce code de conduite s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/).*
